# Fridge food and icon pairings

Reviewed 2026-11-18, including the latest 34 new icons, against the foods actually recognised by the home page. The icon folder now contains 381 SVGs.

The catalogue already contains these groceries. 1,782 food entries now have explicit pairings, using 209 different illustrations including the name-specific choices. Aliases and plural forms inherit their food’s picture. Other recognised foods retain the category illustration.

`src/js/food-icons.js` contains the complete mapping and loads only on the home page. No food keys or recipe matching rules changed. Specific names such as Farfalle, Baguette, Ruccola and Rödkål survive the add form so their artwork can be shown. Unknown items remain unillustrated.
